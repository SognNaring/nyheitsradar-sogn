# Nyheitsradar Sogn

Ei open samlingsside for nyheiter, fristar og analysar som påverkar næringslivet i indre Sogn.
Sida blir oppdatert automatisk kvar vekedag før kl. 07.

- `index.html` og `app.js`: sjølve sida.
- `data/saker.json`, `data/utgaver.json`, `data/meta.json`: innhaldet, som morgonoppdateringa skriv.
- `data/arkiv/ÅÅÅÅ-MM.json`: eldre saker.

Bileta tilhøyrer kjeldene og fotografane som er nemnde på kvart bilete.
